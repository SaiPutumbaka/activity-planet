# Place rules for the hub map (D-041)

Which OpenStreetMap places each hub shows on the map. The design is `docs/design/hub-map/HUB_MAP_DESIGN.md`.

| File                                  | Kind                   | What it is                                                                        |
| ------------------------------------- | ---------------------- | --------------------------------------------------------------------------------- |
| `rules/rules.txt`                     | edit by hand           | One line per hub: confidence, place mode, OSM filters, Geoapify categories, notes |
| `rules/slugs.txt`, `rules/cats.txt`   | edit by hand           | Hub order and categories; must match `supabase/seed/hubs.sql`                     |
| `place_kinds.json`                    | edit by hand           | Display kinds (label, lucide icon) and the base tag to kind map                   |
| `build_rules_json.py`                 | script                 | `rules/` to `hub_place_rules.json`                                                |
| `hub_place_rules.json`                | generated              | Per-hub rules (612 hubs)                                                          |
| `gen_place_rules.py`                  | script                 | JSON, kinds and taginfo counts to the seed, the filter, the id registry and stats |
| `taginfo_counts.json`                 | generated by the job   | Worldwide use counts per tag from taginfo (`places-taginfo.yml`)                  |
| `rule_ids.json`                       | generated, append-only | Stable rule ids and `rules_version`                                               |
| `filters.txt`                         | generated              | `osmium tags-filter` expressions (base tags only)                                 |
| `rules_stats.json`                    | generated              | Counts: rules, base tags, links, verified, dropped                                |
| `../../supabase/seed/place_rules.sql` | generated              | Seed for `place_kinds`, `place_rules`, `hub_place_rules` and `hubs.place_mode`    |

After editing anything by hand:

```sh
python3 -I scripts/places/build_rules_json.py
python3 -I scripts/places/gen_place_rules.py
```

Commit every changed file. CI (`place-rules` in `.github/workflows/ci.yml`) runs both and fails if anything differs.

To refresh the taginfo counts, run the **Places taginfo check** workflow by hand, download `taginfo_counts.json` from its artifact (or copy the counts from its log), put it in this folder and re-run the generator. A tag with fewer than 50 uses worldwide drops its rule (or, as an extra condition, its value); a rule whose tags all reach 50 is marked verified.

The seed needs the slice 3 schema (`place_kinds`, `place_rules`, `hub_place_rules`, `hubs.place_mode`, `hubs.geoapify_categories`), so it is not in `supabase/config.toml` or `migrate.yml` yet; slice 3 wires it in after `hubs.sql`.
